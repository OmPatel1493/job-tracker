# AI-Powered Job Application Tracker

> **Work in Progress** — actively developed as a 6-week portfolio project.

## Description

A full-stack web application that helps job seekers organize and optimize their
job search using AI. Users can track applications across every stage of the
hiring pipeline, paste job descriptions to receive AI-generated resume tailoring
suggestions, and query their own application history through a semantic search
interface powered by vector embeddings. The system surfaces patterns in
rejections and interviews to help candidates focus their energy where it matters
most.

---

## Tech Stack

| Layer       | Technology |
|-------------|------------|
| **Frontend** | Next.js 15, React 18, TypeScript 5, Tailwind CSS, shadcn/ui |
| **Backend**  | FastAPI 0.115, Python 3.12, SQLAlchemy 2.0, Alembic 1.14 |
| **Database** | MySQL (relational) · Pinecone (vector store) |
| **AI**       | Google Gemini (resume analysis + skill extraction) · Gemini Embeddings (semantic search) |
